## 真实 ComfyUI 工作流

通过 ComfyUI 自身的 `/prompt` 和 `/history` 执行并检查结果，全部通过：

1. 文本节点返回并显示模拟供应商的文本。
2. 输入不变时复用缓存，不增加供应商生成请求；修改请求编号后产生新请求。
3. 图像节点连接原生 `SaveImage`，保存两张不同尺寸的图片，PNG 元数据不包含测试密钥。
4. 原生 `LoadImage` 输入识图节点，图片传入请求。
5. 原生 `LoadImage` 输入图片编辑节点，经 multipart 提交并保存返回图片。
6. 修改所选模型的模板使相关缓存失效；异步图像模板完成轮询并连接 `SaveImage`。

复现脚本为 `scripts/smoke_comfyui.py`。它会替换固定测试端口 8191 的插件配置，只可用于隔离开发实例。

## 浏览器交互

在上述真实 ComfyUI 前端中操作并确认：

- 顶部 API 按钮和 Extensions 菜单可打开管理面板。
- 创建供应商、设置名称/图标/Base URL、获取模型、编辑模型并绑定模板、保存配置。
- 测试面板预览及实际请求可以展示返回内容。
- 简体中文与英文切换；切换时保留尚未保存的表单内容。
- 创建并放置 API 节点，选择供应商与模型，运行后查看返回文本。
- 保存并重新载入工作流，供应商、模型、提示词等输入保持一致。

0.2.0 的补充验证：

- LobeHub 图标搜索、Qwen 图标选择、保存和节点显示；322 个图标的本地文件存在性检查。
- 统一模型选择器按节点能力、供应商状态和模板类型筛选，选择时同步供应商与操作类型。
- 勾选多个模型并批量绑定“识图”模板，确认保留各自其他操作的绑定。
- 独立模型编辑页面的“保存并返回”，模型名称在节点中同步更新。
- 0.1.0 保存的工作流可在新界面载入、运行并再次保存。
- 提示词/参数“接入节点”可显示独立插槽；实际拖线连接 `API 参数` → `API 文本 / 识图`，供应商收到并返回 `temperature=0.35`，ComfyUI 报告执行成功。

## 交付边界

安装包只包含运行代码、语言文件、说明及示例；开发虚拟环境、测试数据、配置和密钥文件不参与打包。
